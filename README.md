# 근대사 연표 암기장

1789~1886년 근대사 연표를 퀴즈로 복습하는 모바일 대응 웹사이트입니다. 별도 라이브러리나 빌드 과정 없이 GitHub Pages에서 바로 실행됩니다.

## 문제 유형

- **주요 사건 · 직접 입력:** 원본 엑셀의 `중요도 높지 않음` 열 바깥에 있는 사건 66개를 제시하고, 해당 연도를 숫자로 입력합니다.
- **중요도 낮음 · 4지선다:** 원본 엑셀의 `중요도 높지 않음` 열에 있는 사건 2개의 연도를 보기 4개 중에서 선택합니다.
- 학습 범위 선택, 문제 순서 섞기, 정답 확인, 정답 보기 기능이 있습니다.
- 암기 진도는 브라우저의 `localStorage`에 저장됩니다. 같은 기기의 같은 브라우저에서 유지되지만, 브라우저 간 또는 기기 간에는 동기화되지 않습니다.

## GitHub Pages로 공개하기

1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예를 들어 `modern-history-timeline`이라는 이름을 사용할 수 있습니다.
2. 이 폴더 안의 `index.html` 파일과 `README.md` 파일을 저장소의 가장 바깥쪽(root)에 업로드합니다. 다른 폴더 안에 넣지 마세요.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/ (root)`를 선택하고 **Save**를 누릅니다.
6. Pages에 표시되는 주소로 접속합니다. 보통 주소 형식은 `https://깃허브아이디.github.io/저장소이름/`입니다. 실제 주소는 GitHub Pages 설정 화면에 표시된 값을 사용하세요.
7. 휴대폰에서도 같은 주소를 열면 됩니다. 필요하면 모바일 브라우저 메뉴에서 홈 화면에 추가할 수 있습니다.

## 수정할 때

- 퀴즈 데이터는 `index.html` 내부의 `EVENTS` 배열에 들어 있습니다.
- 이 사이트는 HTML·CSS·JavaScript만 사용하므로 빌드 명령이나 패키지 설치가 필요하지 않습니다.
